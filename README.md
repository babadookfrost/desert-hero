# 🐪 Герой Пустыни: В погоне за термосом

Шутер в духе Serious Sam — играется прямо в браузере, ничего устанавливать не нужно.

## 🎮 Как играть

- Открой `index.html` (или GitHub Pages — см. ниже)
- **Мышь** — осмотреться (если курсор не захватился — зажми ПКМ и веди)
- **W A S D** — движение · **Shift** — бег · **Пробел** — прыжок
- **ЛКМ** — стрельба · **R** — перезарядка
- **1–5** — оружие (5-е, метательное колесо — после покупки «Моноколеса»)
- **G** — вскочить на моноколесо · **[ ]** — чувствительность мыши · **M** — музыка

## 📜 Что внутри

- **5 локаций**: Песчаная арена → Храм ночи → Каньон заката → Трон Владыки → Прорыв через каньон
- **7 типов врагов**, включая Моноколесника 🛞 (бибикает и таранит!)
- **5 видов оружия**: винтовка, дробовик, миниган, ракетница с самонаведением, метательное колесо
- **Сюжет** про верблюда Горба и термос
- **Магазин**: прокачка + легендарное «Моноколесо» за 9999 монет
- **Взрывчатые бочки** с цепной реакцией
- Прогресс и монеты сохраняются в браузере игрока (localStorage)

## 🚀 Развернуть на GitHub Pages

1. Создай репозиторий на GitHub (например, `desert-hero`)
2. Подключи и запушь:
   ```bash
   git remote add origin https://github.com/ТВОЙ_НИК/desert-hero.git
   git branch -M main
   git push -u origin main
   ```
3. На GitHub: **Settings → Pages → Branch: main → Save**
4. Игра будет доступна по адресу: `https://ТВОЙ_НИК.github.io/desert-hero/`
